# Entre nous

Ton journal, rien qu’à toi.

Web app à installer sur iPhone : ouvre **https://eliera9.github.io/entre-nous/** dans Safari, touche le bouton Partager, puis « Sur l’écran d’accueil ».

- Tes pages restent sur ton téléphone, chiffrées avec ton code (AES-GCM, clé tirée de ton code).
- Ce dépôt ne contient que le code de l’app, jamais tes écrits.
- Fonctionne sans internet une fois installée.
